## 变更范围

- 新增现行组合：南朗街道、民众街道、两江新区、和安县、和康县、岑岭县、嘉峪关钢城街道和雄关街道。

## 后续维护

更新时同时同步三张表，核对来源、记录差异和哈希，验证所有别名目标确实存在。CSV 字段目前不允许内嵌逗号、换行或引号；如来源引入这些字段，先升级 CSV 读取器。执行 cargo test --all-features，确保全表正序地址与真实文本边界用例都通过。
